## 🚀 Por que usar o iabox?

O universo de Inteligência Artificial cresce rápido demais. Todos os dias surgem dezenas de ferramentas novas, mas a verdade é que **90% delas são ruído ou sobrecarregam sua rotina**.

O **iabox** resolve isso com **curadoria de elite**. Em vez de perder tempo testando sites aleatórios, você encontra em um só lugar apenas as IAs que realmente entregam resultados profissionais.

- 🎯 **Foco Total:** Interface limpa, escura e sem anúncios ou distrações.
- ⚡ **Navegação em 1 Clique:** Sem pesquisas complexas. Clique na categoria que precisa e veja as opções certas imediatamente.
- 🗂️ **Zero Poluição:** Filtros dinâmicos que escondem o que você não precisa no momento.

## 🤝 Como Contribuir

Conhece uma IA incrível que realmente funciona e merece estar no iabox?

1. Faça um **Fork** deste repositório
2. Crie uma Branch para a sua feature (`git checkout -b feature/NovaIA`)
3. Faça o **Commit** das suas alterações (`git commit -m 'Adiciona a IA X'`)
4. Faça o **Push** para a Branch (`git push origin feature/NovaIA`)
5. Abra um **Pull Request**
